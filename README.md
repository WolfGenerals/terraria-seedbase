# Terraria Seedbase

一个用于探索和分析泰拉瑞亚(Terraria)世界种子的网页工具。

## 网页功能

- **种子分析**: 输入任意泰拉瑞亚世界种子，查看其生成的世界特征
- **随机数预测**: 显示种子对应的随机数序列，用于预测世界生成结果
- **世界参数**: 支持不同世界大小(小/中/大)和邪恶类型(腐化/猩红/随机)
- **实时预览**: 即时显示种子对应的世界生成状态和随机数信息

## 技术特点

- 基于Vue 3 + TypeScript构建的现代化单页应用
- 使用Tailwind CSS实现响应式设计
- 模拟泰拉瑞亚世界生成算法，提供准确的种子分析
- 支持移动端和桌面端访问

## 使用说明

1. 在网页中输入你想要分析的泰拉瑞亚世界种子
2. 选择世界大小和邪恶类型参数
3. 查看右侧面板中的世界状态和随机数信息
4. 根据分析结果决定是否使用该种子

## 注意事项

- 本工具为社区开发，与Re-Logic官方无关
- 分析结果基于公开的泰拉瑞亚世界生成算法
- 适用于泰拉瑞亚1.4.4.9版本
